# Know VAT & ZATCA -- offline ingestion pipeline only.
#
# Deliberately separate from the repo-root requirements.txt (per Mohammed,
# 2026-07-20) -- these are heavy, local-machine-only dependencies that the
# deployed FastAPI gateway never needs (it only reads Qdrant/SQLite that
# this pipeline writes; qdrant-client for that read path is already in the
# root requirements.txt).
#
# torch: install separately with the CUDA index matching your GPU driver,
# e.g.:
#   pip install "torch>=2.6" --index-url https://download.pytorch.org/whl/cu126
#   pip install --upgrade torchvision --index-url https://download.pytorch.org/whl/cu126
# A plain `pip install torch` (or `pip install -r` this file with the
# default PyPI index) silently installs a CPU-only build even when a CUDA
# GPU is present -- confirmed while building this pipeline.
#
# torch>=2.6 specifically (not just any CUDA build) is required -- newer
# transformers refuses to torch.load a non-safetensors checkpoint (which is
# all BAAI/bge-m3 ships) below that version, per a fix for CVE-2025-32434.
# Do NOT "fix" this by pinning an older transformers instead -- that
# reintroduces the vulnerability the version check exists to close, and
# FlagEmbedding's newer API (the `dtype` kwarg to AutoModel.from_pretrained)
# needs a recent transformers anyway, so an old pin breaks differently.
#
# torchvision must be upgraded to match whatever torch version you land on
# (`pip install --upgrade torchvision` with the same --index-url) --
# mismatched torch/torchvision builds fail with
# "RuntimeError: operator torchvision::nms does not exist".
#
# Verify the whole chain with:
#   python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
#   python -c "from FlagEmbedding import BGEM3FlagModel; BGEM3FlagModel('BAAI/bge-m3', use_fp16=True)"
#
# Confirmed working combo (2026-07-21): torch 2.13.0+cu126, transformers
# 4.57.6, FlagEmbedding (latest as of this date), on
# C:\Users\kalim\miniconda3\envs\torchEnv with an RTX 4060 Laptop GPU.
